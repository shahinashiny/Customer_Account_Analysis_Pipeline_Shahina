# Customer Account Analysis Pipeline

## Project Overview
This project implements an end-to-end Azure data engineering pipeline for customer account analysis using Microsoft Azure services.

## Technologies Used
- Azure Data Factory
- Azure Data Lake Storage Gen2
- Azure Synapse Analytics
- PySpark
- SQL

## Project Flow
CSV Files → Azure Data Factory → ADLS Gen2 → Synapse Spark → Synapse SQL Analytics
